# playlist-sync-fox 説明書（PC 版）

対象の版：最初の版（2026-11-05 の設計）
この説明書は設計を元に書いた。実機での確認は未。

## できること

- PC の iTunes のプレイリストを、Android 端末へ同期します。
- PC のアプリはサーバーとして動きます。端末が PC に取りに行きます。
- PC のアプリはトレイに常駐します。曲の変換や iTunes への書き戻しはしません。
- 同期の開始は端末の操作です。手動の同期と、従量制でないネットワークでの自動の同期があります。

## 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows 10、11 |
| iTunes | iTunes 12.x（Windows 版）。Apple Music アプリは未対応です |
| ネットワーク | 同一 LAN、Tailscale、USB テザリングのいずれか |

## 導入

1. GitHub の Releases から PC 版の zip をダウンロードします。更新の確認はアプリ内でしません。新しい版は Releases で確認してください。
2. 好きなフォルダに zip を展開します。JVM が同梱されているため、Java の導入は要りません。
3. 展開したフォルダの実行ファイルを起動します。
4. コード署名をしていないため、SmartScreen の警告が出ます。内容を確認したうえで「詳細情報」から実行します。
5. 起動すると、画面は開かずトレイに入ります。初回だけ、ペアリングの画面が自動で開きます。

「ログイン時に起動」は既定で有効です。端末の自動の同期は、PC のアプリが動いていることが前提です。

## iTunes の設定

PC のアプリは、iTunes が出力する「iTunes ライブラリ XML」を読みます。

1. iTunes の「編集」→「環境設定」→「詳細」を開きます。
2. 「Share iTunes Library XML with other applications」に当たる項目を有効にします。日本語版での項目名は未確認です。
3. 設定の窓の「XML の場所」を確認します。未設定のときは、`%USERPROFILE%\Music\iTunes\iTunes Music Library.xml` を試します。この場所は Apple の文書に無いため、読めない場合は手で指定してください。
4. 指定した場所が読めるか、その場で検査されます。読めなければ結果が横に表示され、保存されません。

iTunes を起動してライブラリを変えると、XML が更新されます。

## プレイリストの選択

メインの窓の上段で、同期するプレイリストを選びます。

1. トレイのアイコンを左クリックして、メインの窓を開きます。
2. プレイリストのチェックボックスを入れます。変更はすぐ保存されます。
3. フォルダにチェックを入れると、配下のプレイリストをまとめて選べます。

- 曲数と合計サイズが表示されます。スマートプレイリストには「スマート」の印が付きます。
- ライブラリ全体、特別な一覧（iTunes 組み込みの項目）、フォルダ自体は選べません。
- フォルダの中に後から足したプレイリストは、自動では選ばれません。
- 選んだプレイリストが XML から消えると、灰色で「見つからない」と表示されます。「外す」で選択から除いてください。自動では消えません。
- 同期中に変えた選択は、次の同期から有効です。

## ペアリング

初回だけ、PC と端末を結び付けます。

1. トレイのメニューの「ペアリングコードを表示」を選びます。ペアリングの画面が開きます。
2. 端末のアプリでペアリングを始めます。
3. PC の画面に出た 6 桁のコードを、端末に入力します。コードは通信には流れません。
4. 両方の画面に「指紋」が出ます。同じかどうか見比べてください。指紋は PC の公開鍵のハッシュです。

コードには有効期限があります。期限が切れた後、または使った後は無効になり、新しいコードは操作するまで出ません。「無効にして作り直す」で作り直せます。失敗が上限を超えると、そのコードは無効になり、しばらく作り直せません。窓を閉じても、コードは無効になります。

### 接続先

ペアリングの画面には、端末が接続する先が表示されます。

| 接続方法 | 手順 |
|---|---|
| 同一 LAN | 端末が自動で PC を見つけます。見つからないときは、画面の「接続先の一覧」の IP とポート（例：192.0.2.10:47800）を端末に手入力します |
| Tailscale | PC の MagicDNS 名を端末に手入力します。名前は PC の画面に表示され、コピーできます。名前を取得できない場合は行が出ません（実機で未確認） |
| USB テザリング | 端末のテザリングを有効にします。端末が PC を見つけられなければ、画面に別行で出るテザリング側の IP を端末に手入力します |

### 端末を入れ直したとき

端末のアプリを入れ直すと、古いペアリングが PC に残ります。

1. メインの窓の「端末と最後の同期」で「ペアリングを解除」を押し、確認します。
2. もう一度、上の手順でペアリングします。

端末側で解除する場合は、端末の操作で行います。

## 画面の見方

### トレイ

トレイのアイコンの左クリックで、メインの窓が開きます。メニューには次の項目があります。

| 項目 | 動作 |
|---|---|
| 状態の表示 | 「待機中」「同期中」「XML が読めない」「ペアリング未済」のどれかです。同期の件数は出ません。進み具合は端末で見てください |
| 開く | メインの窓を開く |
| ペアリングコードを表示 | ペアリングの画面を開く |
| 設定 | 設定の窓を開く |
| ログの場所を開く | ログのフォルダをエクスプローラで開く |
| 終了 | サーバーを止めて終了する。同期中は確認が出る |

警告があるときは、アイコンに印が付きます。警告は通知されません。メインの窓の帯と、アイコンの印だけで知らせます。

### 端末と最後の同期

| 表示 | 内容 |
|---|---|
| 端末の名前 | ペアリング時に端末が申告した表示名 |
| 状態 | 接続中、未接続 |
| 最後の同期 | 日時、結果（完了、一部失敗、中断、失敗、未開始）、件数（足した、置き換えた、消した、除外した） |
| 失敗の種類 | 失敗があれば、その名前 |

- 端末は 1 台だけです。
- 曲名や曲ごとの一覧は PC に送られません。除外された曲の一覧は、端末の結果の画面で見ます。
- 端末が登録されていないときは「端末がありません」と表示され、ペアリングのボタンが出ます。

### 警告

| 警告 | 条件 | 対処 |
|---|---|---|
| XML が読めない | XML が無い、または読めない | 設定の窓で XML の場所を確かめる。iTunes の XML の共有を有効にする |
| XML が古い | 更新日時が設定の日数より古い | iTunes の XML の共有が有効か確かめる。iTunes を起動してライブラリを変える |
| 選択が空 | 選んだプレイリストが 0 件 | プレイリストを選ぶ。端末では消す曲の確認が出ます |
| 鍵が見つからない | この端末の鍵が見つからない | ペアリングを解除して、再ペアリングする |
| 証明書が変わった | PC の鍵を作り直した | 端末で再ペアリングする |

## 設定

設定の窓の変更は項目ごとに検査され、すぐ保存されます。保存ボタンはありません。

| 項目 | 内容 |
|---|---|
| XML の場所 | iTunes ライブラリ XML のパス。読めなければ保存されません |
| 古いと警告する日数 | 0 以上の整数。0 にすると警告しません |
| ログイン時に起動 | 既定は有効 |
| サーバーのポート | 1024〜65535 の整数。変更するとサーバーを再起動します。使用中のポートだと起動に失敗し、警告が出ます。自動では変わりません |
| ログのフォルダ | 表示のみ |

## 困ったとき

| 症状・表示 | 原因と対処 |
|---|---|
| PC に届かない | 端末と PC が同じネットワークか確認します。PC のアプリが起動しているか（トレイにあるか）確認します。Tailscale では、入力した MagicDNS 名が合っているか確認します。ポートが使用中なら警告が出るので、設定で別のポートにします |
| 端末と PC の時計が違う | 時計のずれが数分以上あると、署名が通りません。端末か PC の時計を合わせてください |
| ペアリングし直しが要る | 鍵が合っていません。PC で「ペアリングを解除」してから、再ペアリングします |
| 容量不足 | 端末の空きが足りません。不足分が端末に表示されます。端末の空きを作ってください |
| PC の XML が読めない | iTunes の「XML を他のアプリケーションと共有」が有効か確認します。設定の窓で XML の場所を確認します |
| ファイルが無い | iCloud から未ダウンロードの曲などです。端末の結果の一覧で確認します |
| 途中で切れた | 再度同期します。続きから転送されます |
| 時間の上限 | Android 15 以降の 1 日の上限です。次回の同期で続きます |
| 曲が変わった | 同期の途中で PC の曲が変わりました。再度同期します |
| 保存に失敗 | 端末側の保存に失敗しました。端末の空きと、結果の一覧を確認します |
| 保護付き（.m4p）の曲 | 転送されません |

ログに鍵とコードは出ません。曲のパスは PC のログにだけ出ます。

## データの置き場と削除

| 内容 | 場所 |
|---|---|
| 設定 | `%APPDATA%\playlist-sync-fox\settings.json` |
| ログ | `%LOCALAPPDATA%\playlist-sync-fox\logs\` |
| 鍵 | 設定と同じフォルダの `secrets.bin`（Windows の DPAPI で暗号化） |

- 設定が壊れたときは、`settings.json.bad` に退避され、既定の設定で起動します。ペアリングの鍵は残ります。
- 通信は PC の自己署名の証明書で暗号化されます。鍵のない要求には、LAN の中でも配信しません。

### アンインストール

1. トレイのメニューの「終了」でアプリを終了します。
2. 展開したフォルダを削除します。
3. 上の表の設定とログのフォルダを削除します。鍵もここにあります。
4. 端末側でも、必要なら端末のアプリでペアリングを解除します。

インストーラーは使っていないため、レジストリの登録はアプリが行う「ログイン時に起動」だけです。削除前に設定の窓で無効にしておくと確実です（実機で未確認）。

（設計：B4-5、X5-5）

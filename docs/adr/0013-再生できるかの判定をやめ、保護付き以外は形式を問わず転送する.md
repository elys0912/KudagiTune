# 0013 再生できるかの判定をやめ、保護付き以外は形式を問わず転送する

## 背景

端末で再生できない形式の曲を、端末が判定して扱いを変える設計だった。2026-11-09 の 1 日のうちに、「転送して別の一覧に出す」と「転送しない」の間を行き来した。実機の確認（Android 14 の実機）で、Poweramp で再生できる ALAC が「再生できない形式」と判定され、転送されなかった。判定が OS のデコーダしか見ておらず、プレイヤーが持つデコーダを見ていなかった。

## 選んだ案

再生できるかの判定をやめる。保護付き（.m4p）以外は、形式を問わず転送する。判定の関数と、非対応の曲の一覧を削る。過去の同期結果を読み戻すため、`unsupported_format` の値だけ残す。

## 捨てた案

- 判定を残し、再生できない曲を転送して別の一覧に出す：判定そのものが誤る
- 判定を残し、再生できない曲を転送しない：誤判定された曲が転送されない（実機で発生した）

## 理由

再生できるかはプレイヤーに依存し、アプリが OS のデコーダだけで正しく判定することはできない。

## 悪い面

端末で再生できない形式の曲も転送する。転送の時間と容量を使い、再生できないことには気づけない。
